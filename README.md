# Power Level Calculator

## My first project using Java Syntax

### What is this program?

This project was a university assignment. As a beginner in programming, I decided to create a "Power Level Scouter" based on user information, using a simple syntax. 

The initial base Power Level is set to **100**. Depending on the user's qualifications and habits — such as training frequency and health status. this base number is multiplied by different factors to calculate their Power Level
